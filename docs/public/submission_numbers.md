Generated by `onus export-numbers --metrics deploy_data/metrics.json --findings deploy_data/findings.json --labels /home/nash/onus-runs/labels_scores.json --out docs/public/submission_numbers.md`.

**How to read this.** Every number below is copied from the input files named under each table; nothing is re-estimated here. Proportions are shown as k/n = rate with a 95% interval: Wilson intervals for recall, flag rates, agreement and precision (as stored by the harness), bootstrap intervals for the corpus correlations and differences (as stored by `onus findings`). An interval marked † was not in the input and was computed here as a Wilson interval from the stored k and n. *n* is the number of units the proportion is over (mutations, claims, labelled flags or papers, as the column says); *papers* is how many distinct papers those units come from, which matters because units from one paper are not independent. Recall is read together with each system's flag rate on unmutated papers and its collateral flag rate: a system that flags everything has perfect recall. "not applicable" means no unit qualified (n = 0); "not measured" means the input that would carry the number was not given.
